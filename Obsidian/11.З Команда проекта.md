Приложение З. Команда проекта

**Родитель:** [[11. ПРИЛОЖЕНИЯ]]

Для выполнения работ формируется команда проекта.

В состав команды входит один руководитель проекта, два бизнес-аналитика, один системный аналитик, два UX/UI-дизайнера, четыре разработчика Flutter, пять backend-разработчиков, три QA-инженера, два DevOps-инженера, один специалист по информационной безопасности, один Data/ML-инженер и один технический писатель.

Общая численность команды составляет двадцать три человека.
