 4.3. Требования к серверной части

**Родитель:** [[4. ТРЕБОВАНИЯ К АВТОМАТИЗИРОВАННОЙ СИСТЕМЕ]]

Серверная часть системы должна разрабатываться на языке Kotlin с использованием фреймворка Spring Boot.

Взаимодействие мобильного приложения с серверной частью должно осуществляться посредством REST API.

Для передачи структурированных данных должен использоваться формат JSON.

Основной системой управления базами данных должна быть PostgreSQL 16.

Для кэширования данных должен использоваться Redis.

Для асинхронного взаимодействия между отдельными сервисами должен использоваться Apache Kafka.

Развертывание серверных компонентов должно выполняться в контейнерах Docker.

Для оркестрации контейнеров должен использоваться Kubernetes.

Для автоматизации сборки и развертывания должна использоваться система GitLab CI/CD.
