 4.1. Требования к структуре системы

**Родитель:** [[4. ТРЕБОВАНИЯ К АВТОМАТИЗИРОВАННОЙ СИСТЕМЕ]]

Система должна иметь клиент-серверную архитектуру.

Клиентской частью является мобильное приложение для Android и iOS.

Серверная часть обеспечивает хранение данных, выполнение бизнес-логики, обработку запросов, взаимодействие с внешними системами и предоставление API мобильному приложению.

В состав системы должны входить мобильное приложение, API Gateway, сервис авторизации, сервис пользователей, сервис каталога, сервис поиска, сервис корзины, сервис заказов, сервис оплаты, сервис доставки, сервис программы лояльности, сервис отзывов, сервис уведомлений, сервис рекомендаций, сервис поддержки, аналитическая подсистема, административная подсистема и подсистема мониторинга.
